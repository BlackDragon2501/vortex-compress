# Vórtex Compress

Vórtex Compress, de Vortex Company: crea archivos ZIP con nivel de compresión ajustable (0-9, motor fflate) y extrae ZIPs marcando solo lo que te interesa. Todo se procesa dentro de tu navegador, tus archivos nunca salen de tu equipo. Gratis, sin anuncios y 100% local.

## Stack

- Next.js 16 + React 19 + Tailwind 4 + TypeScript + fflate
- 100% local en el navegador, sin backend y sin variables de entorno

## Desarrollo

```bash
bun install
bun run dev
```

## Producción

```bash
bun run build
```
